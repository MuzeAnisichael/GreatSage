# GreatSage · 大贤者

一个持续感知电脑语音信息、根据全局指令和预设主动或被动回应的桌面秘书 Agent。

名称致敬《关于我转生变成史莱姆这档事》中主角利姆鲁的“大贤者”能力，其英文名称为 **Great Sage**，可参阅 [Crunchyroll 的技能介绍](https://www.crunchyroll.com/news/features/2019/5/3/explore-rimurus-growth-in-this-official-skill-tree)。项目名与开发目录统一使用 `GreatSage`，计划创建同名 GitHub 仓库。

**当前阶段：v0.1 开发与验证。** 用户已确认整体方案并授权实施。核心模块正进行集成与实测；阶段结果和已知限制会持续写入开发文档。

## 首版方向

- 以用户当前 Windows 11 电脑为运行和测试基准。
- 支持麦克风与一个桌面音源同时监听；桌面音源为系统整体或一个指定程序。
- 聚焦人的语音内容，支持对话、旁听问答和主动解释／提醒。
- 首版提醒由当前语音内容和全局预设触发，不包含定时提醒。
- 由全局 Prompt、Skills 和预设控制行为；语音识别、语言模型和语音合成都支持本地与云端，首版优先完善 API 体验。
- 兼容现成 `SKILL.md` 技能目录，支持导入、启停和按需加载指令／参考资料；执行脚本与外部工具的能力安排在后续版本。
- 支持长期记忆、跨会话记忆、上下文压缩、可追溯日志和动态日志显示。
- 持久保存转写、对话、摘要和记忆；原始音频默认仅作短时缓冲，可手动开启本地录音保存。
- 提供多语言文字／语音输出，以及 Q 版桌宠、摸摸、气泡和简单状态动画。
- 后续扩展打开软件、修改文件、执行命令、工具调用及更多电脑信息输入。
