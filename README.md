# GreatSage · 大贤者

一个根据电脑语音信息作出回应的桌面秘书：听你说话、旁听程序声音，结合全局指令、Skills 和跨会话记忆，通过文字、语音和 Q 版桌宠与你交流。

名称致敬《关于我转生变成史莱姆这档事》中的“大贤者（Great Sage）”能力；项目采用自己的界面与桌宠实现。[名称参考](https://www.crunchyroll.com/news/features/2019/5/3/explore-rimurus-growth-in-this-official-skill-tree) · [项目仓库](https://github.com/MuzeAnisichael/GreatSage)

**当前代码为 v0.2 alpha，以 Windows 11、本机 Python 3.11 环境为开发基准。** 已实现语义记忆、冲突裁决、分层摘要、请求审计与语音质量评测。用户已确认 v0.3 以资料检索、纪要／待办／文档产出和受控工具执行为主线；这些任务能力尚未交付。第一次进入仓库可先看[项目现状](docs/project-status.md)与[路线图](docs/roadmap.md)。

真人朗读经过完整 API 链路的三轮测试中，首字 P50 约 3.14 秒、音频就绪约 4.90 秒；原定首字 1–2 秒、语音起播 2–3 秒目标尚未达到。音频就绪不等于实际播放。样本与未验收项见[v0.2 验证记录](docs/validation-v0.2.md)。

## 当前能力

- 麦克风与一个桌面音源同时监听；桌面音源选择系统整体或一个指定程序及其进程树。
- 对话伙伴、旁听助手和主动秘书三种预设，结合可编辑的全局 Prompt。
- ASR、LLM、TTS 分别配置云端 API 或本地方案，允许混用；LLM 支持 OpenRouter、OpenAI 兼容接口和 Ollama。
- 稳定转写、流式回答、分句语音、手动或麦克风打断，以及清晰的错误与状态显示。
- 长期记忆、跨会话混合检索、冲突待确认、三层后台摘要、来源回查、原文分页、修正与级联删除。
- 只读导入现成 `SKILL.md` 目录，按需加载指令与相关文本资料。
- 独立桌宠、摸摸互动、气泡、状态动画、托盘与主控制台。
- 动态事件日志、交互 trace ID、受控请求快照及导出、配置与实际 Skill 版本、阶段耗时和服务返回的用量信息。

当前音频能力只识别人的语音内容。**不包含定时提醒、打开软件、修改文件、命令执行、外部资料库或纪要／待办／文档任务流程。** Skill 目前只读引用，不执行脚本或工具。“提醒”指对当前内容作出解释或提醒，不会创建闹钟和日程。

后续 v0.3 将以“文字／语音和资料→带出处纪要→可编辑待办→文档”为首个完整任务，并加入受控工具、任务取消／恢复和 Windows 安装验收。待办首先是可编辑清单，具体格式与工具权限会在该阶段确定。v0.4 再扩展屏幕、窗口等输入和更多平台。

## 从源码启动

需要 Windows、Python 3.11 和 Node.js/npm。以下是 API 优先的开发安装方式，不会下载大型语音模型：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
npm.cmd ci
npm.cmd start
```

使用本地语音识别或 Windows 系统语音时，补充可选依赖：

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[local]"
```

也可运行 `scripts/setup.ps1` 一次安装开发与本地语音依赖。安装依赖不等于下载识别模型；本地 ASR 模型需在设置中明确准备，开始监听只加载已有缓存。Ollama 的安装、模型下载和服务启动由用户管理。

启动后在“设置”中分别选择识别、语言模型和语音服务，保存后测试连接，再回到“对话与感知”选择音源并开始聆听。首次默认不开启监听、语音播报和录音保存。不同服务的 ASR、LLM、TTS 支持范围独立，请按实际支持的模型配置；LLM 连通不代表音频接口可用。

API 密钥可使用已有环境变量，或在设置中输入后由 Windows DPAPI 加密保存。空密码框保留已配置的密钥，界面不会回显密钥。`.env.example` 是变量说明，当前不会自动加载 `.env` 文件。

## 构建本机目录包

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[build,local]"
npm.cmd run package
```

构建结果为 `release/win-unpacked/GreatSage.exe`，需要保留同目录的全部文件。这是 Windows x64 目录包，尚未制作安装器、提供 GitHub Release 安装包或配置发行代码签名；fork 后可按上面的命令在本机构建。双击后默认使用 Electron 的用户数据目录；可通过 `GREATSAGE_DATA_DIR` 指定独立数据目录。API 默认配置见[服务说明](docs/providers.md)。

## 使用与数据

“旁听助手”对明确叫名和请求快速回应，对含糊提问使用有时间上限的语义判断；可以在设置中关闭语义判断。要求安静、引用或转述会受到抑制。“主动秘书”需要打开允许主动回应，由模型结合全局指令判断是否值得插话，并受最短间隔和重复内容去重约束。手动发送文字始终视为直接请求。

语义检索默认关闭，在“设置 → 语义记忆与审计”配置 API 或 Ollama 嵌入模型后启用；云端建索引会发送已有历史文本。完整请求快照也默认关闭，日志页可以查看元数据或显式导出已归档正文。新版本自动迁移旧数据库字段，升级前可在退出应用后备份运行目录。

可以说“记住：我喜欢简短回答”，也可以在“长期记忆”页面手动添加。新会话和应用重启不会清空记忆。删除记忆与删除原文的范围不同，操作前可查看[记忆、删除与 Skills 使用说明](docs/usage.md)。

| 数据 | 默认策略 |
| --- | --- |
| 转写、对话、摘要、显式记忆 | 保留至用户删除 |
| 详细审计事件、请求快照 | 保留 30 天，可配置；快照默认仅元数据 |
| 原始录音 | 默认不保存；开启后保留 7 天，可配置 |
| API 密钥 | 环境变量或当前 Windows 用户的 DPAPI 密文 |

源码桌面启动的运行数据保存在项目 `.runtime/`；独立 Python 服务默认使用 `%LOCALAPPDATA%/GreatSage`，可用 `--data-dir` 指定。运行目录、真实对话、录音、数据库和个人 Skills 不进入版本管理。

## 当前限制

- 识别使用 VAD 分段和重复音频快照产生临时转写，**不是语音服务的原生流式识别**；持续说话时可能反复调用 ASR。
- 自身声音处理使用进程排除、播放参考和桌面音源文本去重等措施，**不是完整声学回声消除（AEC）**。麦克风仅使用保守声学抑制，不因文字相似而丢弃用户复述。扬声器、噪声、双人重叠发言仍需实测；耳机有助于减小声学回流。
- 语义判断、冲突建议和摘要都可能出错。语义服务超时会保持安静；检索超时回退关键词。来源原文保留，不把模型建议当作已确认事实。
- 云端配额、模型可用性、网络和本地模型性能会影响整条语音链路；真实配置与性能结论以验证报告为准。
- 目录包已在本机验证，其他电脑兼容性、安装器与发行签名尚未验收。
