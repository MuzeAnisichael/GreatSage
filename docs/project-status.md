- v0.5 alpha（2026-10-22）：最终运行代码 `b4ffe01` 的冻结语音依赖、后端 **14/14**、shutdown／EOF 和包内桌面 **41/41** 通过；语音定向与审批时序检查通过。无本轮真实设备或独立服务测试，完整构建、报告和哈希见 [v0.5 验证](validation-v0.5.md)。

- v0.4 交付验收（2026-10-20）：OpenRouter `google/gemini-2.5-flash-lite` → Microsoft Learn MCP 与 Ollama `qwen3:8b` → 虚构文件的真实工具闭环通过；最新包内桌面组件 **32/32**、冻结后端重启／工具／产物 **14/14**。上下文预算和 4b 模型模板限制均已记录；这些是单例能力检查，审批走应用入口，不是人工点击／真实语音验收。CI、早期回归与本次产物边界见 [v0.4 验证](validation-v0.4.md)。

- v0.2 本机自动回归 **187 passed、4 skipped**；Windows CI 对 0.2.0-alpha.1 提交通过。源码桌面 23 项、包内页面与冻结后端 29 项检查通过。测试没有打开真实麦克风。
- 采用获得授权的公共真人朗读和真实 API 测量，完整语音管线三轮的首字 P50 约 **3.14 秒**，音频就绪 P50 约 **4.90 秒**。此前确定的首字 1–2 秒、实际语音起播 2–3 秒目标尚未达成；音频就绪也不能替代实际起播测量。
- 固定小型场景、虚构记忆和 32 个虚构会话的成绩只证明相应样本上的表现。测试样本、方法、限制和复现命令见[v0.2 验证记录](validation-v0.2.md)与[可重复评测](evaluation.md)。

## 从哪里开始

- 想试用或从源码启动：阅读[README](../README.md)和[使用说明](usage.md)。仓库提供构建脚本；不要只复制目录包里的可执行文件。
- 想继续开发：阅读[贡献与开发](development.md)、[架构](architecture.md)和[记忆设计](memory-design.md)。运行数据、录音、密钥、个人 Skill 与测试输出都应留在忽略的本地目录。
- 想了解计划：阅读[路线图](roadmap.md)。其中“已实现”“尚待验收”和“计划”分别标注；版本目标不代表已经交付或承诺日期。

项目用 `CHANGELOG.md` 区分已发布版本与 Unreleased 改动；各版本方案保留当时确认的范围，[v0.6 方案](v0.6-plan.md)记录本轮记忆与实体。下一阶段为 v0.7 Deep Agents／隔离子 Agent，正式实施前确认任务委派、权限、预算和恢复边界；真实语音及安装反馈作为持续维护项，不以未达性能数值阻塞下一阶段。
