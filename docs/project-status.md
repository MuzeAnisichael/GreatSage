# 项目现状

更新日期：2026-09-29。当前代码版本为 **0.2.0-alpha.1**，主要开发和验证环境是 Windows 11、Python 3.11。本页帮助第一次进入仓库的读者分清已经实现的机制、实测结果与未来目标。功能细节见[需求与验收](requirements.md)，后续顺序见[路线图](roadmap.md)。

| 领域 | 当前进度 | 验证边界 |
| --- | --- | --- |
| 输入与回应 | 文字、麦克风、系统整体或单个进程树音频；三种回应预设；流式文字、分句语音、打断与新会话 | 真实麦克风、设备变化、房间回声和自然会话仍需更多实测；新会话与旧会话浏览已经实现，返回旧会话继续执行任务尚未实现 |
| 模型与资料 | OpenRouter／兼容 API 和 Ollama 可分别配置；只读引用 Skill 文本；历史、记忆和摘要的词法／可选语义混合检索 | 尚无通用文件资料库的导入、解析、更新和带出处检索流程；云端语义索引会向所选服务发送文本 |
| 记忆 | 显式事实与偏好、跨会话原文、三级摘要、来源依赖、记忆冲突裁决、修正及删除传播；来源和部分对象有版本记录 | 普通陈述不会自动确认为用户事实；复杂关系保持、大规模历史和完整版本回滚尚未验证或实现 |
| 审计与后台 | 动态事件、trace、默认元数据的请求快照、显式正文归档／导出；后台有限批次、失败退避及索引／压缩续作 | 已有后台续作不代表任意多步骤用户任务都能在崩溃后继续 |
| 桌面交付 | Electron 主窗口、桌宠和托盘；本机 Windows x64 目录包可构建，包内组件通过桌面检查 | 尚无安装器、发行签名、干净电脑安装／升级／卸载验证或可下载的 GitHub Release 安装包 |
| 任务与工具 | 可以回答、解释、按当前内容提醒；Skill 只读 | 资料任务的纪要／待办／文档产物、打开软件、修改文件、命令与外部工具执行均属后续规划；没有定时提醒 |

## 已有证据

- v0.2 本机自动回归 **187 passed、4 skipped**；Windows CI 对 0.2.0-alpha.1 提交通过。源码桌面 23 项、包内页面与冻结后端 29 项检查通过。测试没有打开真实麦克风。
- 采用获得授权的公共真人朗读和真实 API 测量，完整语音管线三轮的首字 P50 约 **3.14 秒**，音频就绪 P50 约 **4.90 秒**。此前确定的首字 1–2 秒、实际语音起播 2–3 秒目标尚未达成；音频就绪也不能替代实际起播测量。
- 固定小型场景、虚构记忆和 32 个虚构会话的成绩只证明相应样本上的表现。测试样本、方法、限制和复现命令见[v0.2 验证记录](validation-v0.2.md)与[可重复评测](evaluation.md)。

## 从哪里开始

- 想试用或从源码启动：阅读[README](../README.md)和[使用说明](usage.md)。仓库提供构建脚本；不要只复制目录包里的可执行文件。
- 想继续开发：阅读[贡献与开发](development.md)、[架构](architecture.md)和[记忆设计](memory-design.md)。运行数据、录音、密钥、个人 Skill 与测试输出都应留在忽略的本地目录。
- 想了解计划：阅读[路线图](roadmap.md)。其中“已实现”“尚待验收”和“计划”分别标注；版本目标不代表已经交付或承诺日期。

项目用 `CHANGELOG.md` 记录已经交付的版本行为；`docs/v0.1-plan.md`、`docs/v0.2-plan.md` 是各阶段的历史方案。后续需求应进入需求与路线图，再由验证记录给出交付证据。
