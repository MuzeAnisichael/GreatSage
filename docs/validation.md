# v0.1.0-alpha.1 验证记录

验证日期：2026-09-04。基准环境为 Windows 11、Python 3.11.7、Node.js 24 和 Electron 40；本机 Ryzen 9 8945HX、约 32 GB 内存。以下只说明本轮已经验证的行为。

## 自动化与真实界面

自动化回归覆盖音源格式、VAD 分段、服务流式解析、上下文预算、取消、过期任务、删除级联、记忆修正、Skill 文件边界、DPAPI 配置、REST/WS 鉴权和播放参考。硬件采集、SAPI 和需要额外 Windows 权限的符号链接测试有独立条件；默认测试不启动监听或调用收费 API。

本机完整回归结果：**155 passed，4 skipped**；跳过项为显式启用的两项音频硬件测试、SAPI 实机测试和需要额外权限的符号链接测试，相关采集与 SAPI 能力另有下述实机验证。JavaScript/CJS 语法检查通过。仍有 Python audioop 与 FastAPI TestClient 的依赖弃用提示。

GitHub 仓库已启用 Windows CI，核心实现提交 `9bc0ef1` 的 Windows 运行已成功。运行命令为 `python -m pytest -q`、`npm run check` 和 `python scripts/check_repository.py`；后续提交的状态以仓库 Actions 为准。

真实 Electron 宿主通过自身 preload 连接真实 Python 子进程，已经验证：

- 读取实际音频设备和进程列表，切换设置并保存。
- 合成测试记忆的添加、修正、删除；导入的 Skill 显示。
- OpenRouter 流式文字 → Windows 中文 SAPI → HTMLAudio 播放事件。测试将输出静音，因此不构成扬声器听感验证。
- 停止回应后前端音频和后台说话状态均停止，动态日志筛选与追踪展开。
- 原创桌宠、摸摸爱心、对话气泡、置顶、鼠标穿透、显示与收起。
- 退出时清理自身后端子进程，测试期间没有启用麦克风或桌面监听。

桌宠请求尺寸为 360×420；本机 Windows DPI 舍入后报告 361×421。测试允许 1 像素舍入差异。

最终提交版 `scripts/smoke_desktop.cjs --parallel-sources` 在真实 Electron 中 **19/19 检查通过**，未调用模型或开启监听。补充验证了并发设备枚举、超过最近 100 条的来源回查、只读摘要来源点击，以及删除原文后关联回答从聊天界面移除。

## 真实采集与本地语音

原生采集测试分别验证麦克风、系统音频和指定进程。合成 660 Hz 信号的进程包含捕获平均幅度为 2986.4，排除此进程后为 0；该测试验证进程选择，不是语音识别质量测试。一次停止耗时约 110 ms。麦克风和系统同时采集也已返回不同来源的数据；它们进入不同分段器。

真实 Electron 联调曾复现并发设备枚举导致 PortAudio 原生访问冲突。已改为进程共享的单一 owner 线程和带引用计数的设备生命周期，并验证 8 次双并发枚举无错误。修复后的麦克风在约 1.1 秒采集中同时完成两次枚举，返回 19 个 PCM 块，停止耗时 47 ms，采集与分发线程均退出；没有保存、转写或输出音频内容。

本机 Whisper base 权重已从官方模型仓库下载并成功加载。CPU/int8、4 线程、beam size 3 的两条合成样本：

| 输入 | 实际转写 | 识别耗时 |
| --- | --- | ---: |
| 请记住，我喜欢简短的中文回答。 | 請記住,我喜歡簡短的中文回答。 | 415 ms |
| Please remember that I prefer short answers. | Please remember that I prefer short answers. | 376 ms |

中文样本内容一致但采用繁体；首版保留原文，并已让显式“记住”指令兼容简繁体及逗号。该两条结果不代表人名、数字、噪声或中英混合场景的整体准确率。

云端模型、费用字段和中文 ASR 对照见 [服务配置与实测](providers.md)，完整的分阶段耗时见 [性能基线](performance-baseline.md)。

## 本机目录包

使用 PyInstaller 构建独立后端，Electron Builder 生成 Windows x64 目录包。已在没有调用项目 Python 解释器的情况下验证冻结后端启动、REST 鉴权、真实音源枚举、系统中英文音色、SAPI 合成和本地 Whisper ASR。冻结后端的英文合成与转写组合测试为 534 ms，包含 SAPI 生成输入的时间。

该交付是本机可试用的目录包，不是经过其他电脑兼容验证的安装器。需要保留 `GreatSage.exe` 旁的全部资源。未配置发行代码签名证书；不宣称具有受信任的发行签名。

## 尚未验收

- 真人多轮语音、人名、数字、专业术语、中英混合的准确率。
- 扬声器回流、双讲与长期监听下的稳定性；当前回声门控不等于完整 AEC。
- 语句结束到实际扬声器起播、真实麦克风打断的 P50/P95 指标。
- 多小时运行、设备热插拔、网络反复恢复以及其他电脑兼容性。

因此版本标记为 alpha。单条合成输入的成功不能被表述为所有已确认性能目标均已完成验收。
