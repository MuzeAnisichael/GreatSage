# v0.2 开发验证记录

2026-09-27，分支 `feat/v0.2-quality-memory-audit`。开发中的阶段证据，不等同于全版完成。

## 固定基线

`evals/decisions.json` 为项目编写的 20 个对话边界场景，不是真人会话样本。v0.1 规则准确率 0.65，7 个误触发、0 个漏触发。`evals/memory.json` 是 6 条虚构记录和 5 个改写查询，v0.1 词法检索 Recall@3 为 0.20。结果保存在 `evals/baseline-v0.1.json`；语料哈希按规范化 JSON 计算，避免 Windows 换行影响对比。

## 语义记忆与预算阶段

- 自动化：166 passed、4 skipped；`npm run check` 通过。
- 使用本机已配置凭据，真实 OpenRouter `openai/text-embedding-3-small`：5 个查询 Recall@3=1.0，P50=594 ms、P95=618.8 ms。六次嵌入请求（一次记录批次、五次查询）共 245 个输入 tokens，服务返回总成本约 0.0000049 美元。
- 本机 Ollama `bge-m3:latest`：5 个查询 Recall@3=1.0，P50=2328 ms、P95=2581.2 ms，部分重复文本查询命中服务缓存，不能将 16 ms 当作普通查询时延。首次使用 15 秒后台超时触发失败；后台请求上限调整为 60 秒后完成。前台检索有独立等待上限，默认 1.5 秒，因此慢查询将回退词法检索；上述召回率是未应用前台等待上限的嵌入能力测量。
- 真实下载并校验 `o200k_base` 编码文件成功；默认 Gemini 模型继续使用保守字节预算。明确支持的 GPT 编码只有手动准备后才启用，不将通用编码描述为所有模型的精确计数。
- 运行报告保存在忽略目录 `.runtime/eval/`。测试只使用虚构记录，不向服务提交用户历史。

向量删除/修正失效、维度变化、模型隔离、无效响应、后台过期提交和旧版配置兼容均有自动化覆盖。此阶段的新桌面控件仅完成语法检查，完整交互和打包验证在整合阶段执行。

## 记忆、审计与语音整合阶段

- 冲突候选隔离、替换/丢弃/共存、来源删除失效、旧会话压缩、分层回查和分页已实现。请求快照默认只有哈希和元数据，全文需先开启，正文上限 256 KB；来源删除会失效，日志保留期同样适用，重启标记未完成请求。
- 结构化旁听判断真实调用 OpenRouter `google/gemini-2.5-flash-lite`，20 个固定文本场景全部符合标签，无服务失败，P95=745.75 ms（包含规则快速路径）。早先仅约束提示词的试验有 2 次格式失败和 1 个漏答；加入结构化输出后复测上述结果。固定开发集成绩不代表陌生会话的泛化准确率。
- Google FLEURS CC BY 4.0 中文 validation 的 3 段真人朗读（18.38/7.44/7.56 秒），重复 3 轮共 9 次识别，字符错误率 5.079%，请求到识别完成 P50=1500 ms、P95=2106.2 ms，失败 0。原始文本及授权信息在 `evals/speech.json`、`evals/audio/ATTRIBUTION.md`。不是自发交谈样本。
- 同一组录音降为 15% 幅度，单轮 3 次 CER=4.762%，P50=1563 ms、P95=2364 ms；仅验证 ASR 接口，没有经过真实麦克风或 VAD。
- 使用真人录音进行数字模拟：0.4 倍参考声、180 ms 延迟、另一段 0.5 倍人声重叠。20/100 ms 音频批次中，纯回声的 382 个有效语音帧被抑制，重叠情况下 664 个独立人声帧没有被静音。100 ms 批次滤波 P95 约 0.7 ms。这不是房间回声实测或完整 AEC。
- 全套中间回归 174 passed、4 skipped；随后新增的故障/取消/过期决策/审计导出定向检查 15 passed。正在执行桌面与打包整合检查。

本轮测试只使用虚构记录及明确授权的公共录音，未提交用户历史。详细报告在忽略目录 `.runtime/eval/`，最终发布前会补充整体结果。
