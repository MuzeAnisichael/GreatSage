# v0.7 资料核对与文档闭环

确认日期：2026-11-18。用户批准范围并要求小切片提交、同步开发日志与文档，完成后交付 main。基线为 v0.6 alpha / `f369143`。

## 本版任务

选择 Markdown 资料与会话 → 显示计划 → 只读资料整理 → 只读证据核对 → 生成带引用的文档 → 审阅并审批保存到工作目录。普通问答和既有纪要继续使用现有短路径。

- 复用 Deep Agents 的有界代理运行能力，先提供资料整理与证据核对两个固定职责。子 Agent 不获得宿主文件系统、命令、网络、MCP、审批或记忆写入能力，不递归委派；仅能读取父任务选定的资料快照及只读 Skill 文本。
- LangGraph 继续负责外层步骤与恢复，checkpoint 只含控制状态与引用；原始正文、阶段结果和产物由现有 SQLite 数据层管理。
- 文档事实附来源；程序检查来源身份、逐字证据与结果结构，模型核对作为辅助审阅，不宣称自动证明事实正确。缺失、冲突和无法支持的结论明确标示。
- 保存复用现有工具权限与账本。保存授权绑定产物版本，来源或产物变化时拒绝过时授权；拒绝保存保留可审阅文档，不伪报已保存。
- 调用次数、上下文、输出与时间有上限，显示任务计划、子任务状态和实际服务用量（缺失费用不按零费用展示）。取消、来源删除、设置变化与恢复不得接纳过期结果；未知副作用不重放。
- 渐进 Skill 加载仅限注册且启用的文本，不执行脚本。自动提取记忆不成为研究任务的前置或副作用。

## 切片与验收

1. 框架薄适配与只读边界：核对并固定实际 Deep Agents 版本、许可证和默认行为；离线覆盖真实框架、预算与非法能力调用。
2. 任务及数据闭环：收集、计划、整理、核对、产物、审批保存；覆盖成功、拒绝、取消、来源变化、版本变更及中断恢复。
3. 控制台入口与监控：保留纪要入口，增加资料文档任务，明确展示待核对内容和保存状态。
4. 最小固定样本对比既有流程与新流程，记录正确性、遗漏、耗时和费用；合成验证与真实模型分开记录。必要 CI、构建与发布检查一次收敛，不重复付费追指标。
5. 同步代码导航、架构、使用说明、现状及验证，保留切片交付 main。

## 边界

本版不增加任意自主桌面操作、递归 Agent、Skill 脚本执行、PDF/Word/网页导入、屏幕感知或定时提醒。真实语音、安装升级和长期使用作为持续维护项保留；不把未测项改写为通过，不以旧延迟目标阻塞本版功能。
