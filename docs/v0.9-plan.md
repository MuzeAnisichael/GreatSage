# v0.9 跨天工作接续

2026-11-18 已确认，基线为 main `57fcb4c`。以旧项目会话为入口，默认接上次进展。明确询问昨天或选择日期时按本机日历过滤会话原文，额外 Markdown 由用户选取。范围、空时段和引用应可核对。

简报包括已确认的决定、下一步和待确认事项。建议单独标记。来源明确说明时才写负责人、日期及完成状态。每项支持回看来源，冲突或候选日期要保留不确定性。

文字与语音共用纠正入口。用户主动开始、停止语音录入，先编辑转写，再提交修改要求。纠正作为独立用户来源，修订同一文档、查看版本差异，保留无关事项和引用。写工作目录另行审批，绑定生成版本及内容哈希。拒绝后保留简报，切换、来源更改及重启撤销过期授权。
