## 指标与验收边界

- `first_audio_ms`：语音结束到 HTML `playing` 回执到达后端，包含回传时间；`client_event_to_playing_ms`：收到音频事件到 `playing`。`audio_ready_ms` 只到合成完成。
- `interrupt_to_stop_ack_ms`：后端打断到收到客户端停止确认，`client_stop_ms` 是客户端 pause/reset 时间；两者都不是声卡实际静音。
- 监控卡片各取最新有效样本，可能来自不同回复。无记录是“待测”，不代表零延迟。
- 初版流式服务在上一话轮尚未确认时又开始新话轮会停止该源，需要重开监听；真实连续交流适用性尚未验证。故障不自动切换提供方。
- 无 `DEEPGRAM_API_KEY`，真实新服务连接／中文质量／端点速度／费用均未测。可以完成本地协议和生命周期验证，不能声称该服务已在本机通过。
- 源码／包内组件检查不等于原生 EXE 安装验收；同版本覆盖不等于跨版本升级。NSIS 安装器会写当前用户注册项、快捷方式、安装缓存和临时文件，不能声称所有写入都在隔离数据目录。
- 真实麦克风、系统／指定进程、设备切换、扬声器回声、重叠发言、自然会话、整天运行、干净电脑和完整安装链仍待测。现有回声门控不是完整 AEC。
