# GreatSage v0.3 开发方案

2026-09-30：用户确认 v0.3 的待定细节，并要求开始开发、开发后测试性能参数：

- 首批资料格式只支持 `.md`；产物以 `.md` 为主。
- 工具授权参照当前主流前沿 agent 的做法设计。
- 可能有副作用的操作默认需要鼠标点击确认；可以在设置中授权语音确认，但开启时必须弹出警告窗口。
- 详细任务进度显示在控制台，桌宠气泡只显示简化版。

本文是 v0.3 的范围记录。完成状态以 CHANGELOG、验证记录和评测报告为准，本文不把计划记为已实现。

## 交付范围

| 方向 | 本版交付 | 验收依据 |
| --- | --- | --- |
| 资料与引用 | 导入 `.md` 文件或目录；按标题和段落分块，记录标题路径、行号和内容版本；重新扫描发现修改后生成新版本；删除或修改使旧引用失效；资料参与对话检索 | 出处可定位到文件、标题和行；修改／删除后旧引用失效；资料内容只作参考数据，不能变成指令 |
| 结构化产物 | “会话原文与资料 → 带出处纪要 → 可编辑待办 → 文档草稿”；纪要由模型抽取结构化条目、程序渲染 Markdown；待办可逐条编辑；文档草稿要求逐句标注出处；支持修改、带纠正说明的重新生成和导出 `.md` | 姓名、负责人、期限只取原文明确出现的内容，否则标“未确认”；引用标记必须指向本次提供的来源；修订保留版本 |
| 任务生命周期 | 任务与对话回复分开运行；持久化任务和步骤结果；显示进度；可取消；重启后标记为中断并可从未完成的步骤继续 | 迟到结果不写入其他会话；取消后状态明确；重启不重复执行已完成步骤，不自动重放有副作用的工具调用 |
| 受控工具 | 统一工具注册、参数校验、效果分级、授权规则、审批、执行记录和可撤销操作；首批提供工作目录内的文件读写、导出产物、打开文件／网址、启动设置中登记的程序、移入回收区，以及默认关闭的命令工具 | 旁听内容、资料和工具结果都不能授权操作；未批准的副作用操作不执行；每次调用可追溯参数、来源、审批方式和结果 |
| 评测 | 固定任务集、离线正确性检查和真实服务性能测量 | 首段反馈、步骤耗时、任务总耗时、用量、引用有效率、待办抽取、越权拦截和对话首字时延分别报告 |

Windows 安装器、升级／卸载验收和 MCP 接入不在本轮实现，保留为 v0.3 后续里程碑。

## 工具授权设计

参照 Claude Code、Codex 等 agent 的权限模型和 MCP 的工具注解：

- **效果分级**：每个工具声明效果类别：`internal`（只生成应用内产物）、`read`（只读）、`write`（可撤销的写入）、`launch`（打开文件、网址或程序）、`destructive`（删除类）、`execute`（执行命令）。
- **默认策略**：`internal`、`read` 直接执行；`write`、`launch`、`destructive` 每次询问；`execute` 默认禁用，在设置中开启后也要每次询问。
- **规则**：设置中可以为工具加“允许／询问／拒绝”规则，按目标路径、网址或命令用通配符匹配；优先级为拒绝 > 询问 > 允许。`destructive` 和 `execute` 不接受“始终允许”规则。
- **授权范围**：审批时可以选“仅本次”，写入和打开类也可以选“本任务内允许”。任务授权只在当前任务有效，不会写入设置。
- **指令来源**：只有你的文字、麦克风请求或控制台操作发起的任务可以调用工具。旁听内容、导入资料、Skill 和工具返回结果都视为不可信数据，不能发起或批准操作。
- **沙箱**：文件工具只能访问工作目录（默认是运行数据下的 `workspace/`，可在设置中追加目录）；路径解析后必须仍在工作目录内。首批写入只允许 `.md` 和 `.txt`。
- **确认方式**：默认在控制台点击确认。开启语音确认要先确认风险警告；开启后只接受麦克风里完整的“确认执行”“取消执行”等短语，只适用于写入和打开类操作，删除和命令始终需要点击。
- **审计与撤销**：记录参数、效果、发起来源、审批方式、结果和错误。覆盖写入先备份，删除只移入回收区，这两类可以撤销；打开和命令无法撤销，会明确提示。
- **重启**：执行中断的调用标为“结果未知”，不会自动重试。

## 交互

- 控制台新增“任务与产物”和“资料库”两个页面：任务列表、步骤进度、待确认操作、产物查看／编辑／导出，以及资料导入、扫描和删除。
- 对话中可以直接说“帮我整理刚才会议的纪要”，模型通过内部工具创建任务；控制台也可以手动新建任务。
- 桌宠气泡只显示简化进度，例如“正在整理纪要 · 2/4”“有 1 项操作等你确认”。

## 测量

先用离线夹具检查正确性和本地耗时，再用当前配置的真实服务测量：

- 资料导入和本地检索耗时。
- 任务的首个进度事件、抽取首字、各步骤和总耗时，以及 token 用量和费用。
- 待办和负责人抽取与标注的一致性，引用有效率。
- 资料中的恶意指令能否被拦截。
- 附带工具定义前后的对话首字时延。

样本数、失败和未测场景一并报告。
