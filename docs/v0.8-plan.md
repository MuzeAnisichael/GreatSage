# v0.8 可持续使用的资料工作台

确认日期：2026-11-18。基线 main `ca9ea89` / v0.7.0-alpha.1。用户已确认范围与默认交互 A：在明确选定资料／会话中自动选取相关片段后执行，按需查看和调整；完成后以小切片提交交付 main。

## 最小完整流程

返回昨日会话 → 继续交流并查看关联任务／文档 → 从较长 Markdown 中按问题选取证据 → 审阅结论／原文 → 补充纠正或更新资料 → 核对新旧版本 → 重新点击批准保存。

## 交付范围

1. **会话继续**：显式切换并继续历史会话；重启恢复会话入口，不自动重启模型任务。切换撤销旧运行身份，未完成任务显式继续，旧回答、转写、审批不能污染新会话。
2. **自动选择来源**：复用现有 SQLite/FTS 和来源版本机制，只在所选资料／会话内排序；提供实际读取范围、固定与排除片段及预算说明。自动运行不额外增加确认步骤；不静默扩大范围、截断证据或把局部检索当作全文覆盖。全文要求、固定片段或预算无法满足时明确停下。
3. **连续审阅与修订**：复用产物版本、引用与审批，关联原任务、修改要求与新旧产物，展示文本差异和来源失效。用户纠正单独保存为用户来源；旧模型产物仅作待修改对象，不作为原始证据。
4. **审批和恢复**：每次保存绑定当前产物版本／内容哈希；来源变动与过期授权失效，拒绝保留产物，未知副作用不重放。恢复复用已完成阶段，重新校验待执行阶段。

## 实施与验证

按会话后端、来源选择、产物关联与修订、工作台界面、交付文档分片。复用现有框架，不新增代理底座或重做通用检索系统。权限／来源／并发／持久化边界使用定向回归；跨模块验收覆盖上述完整流程，完整源码回归交给 CI，构建与真实模型只在功能收敛后按需验证。

普通问答和纪要继续保留短路径；研究的角色和模型调用上限保留，较长资料先在本地选取有界原文。本版先使用原有 Markdown 格式，不承诺无限资料或全文研究。

## 本版不包含

PDF／Word／网页导入、屏幕感知、通用递归／并发 Agent、实体消歧重构、跨平台、定时提醒或此前搁置的首配清单。语音和安装仅修复实际阻塞问题；真实设备、人工安装／升级和长期运行未测项继续保留，不用历史证据冒充本版通过。
